Лекция 6
Циклы

Цель лекции: Изучить различные типы циклов в языке C#, их применение и синтаксис.

6.1 Цикл while
Цикл while используется для повторения блока кода, пока условие истинно.
Синтаксис:
while (условие)
{
    // блок кода
}

6.2 Цикл do-while
Цикл do-while выполняется хотя бы один раз, а затем проверяет условие.
Синтаксис:
do
{
    // блок кода
} while (условие);

6.3 Цикл for
Цикл for используется для повторения блока кода определенное количество раз.
Синтаксис:
for (инициализация; условие; инкремент)
{
    // блок кода
}

6.4 Вложенные циклы
Циклы могут быть вложены друг в друга для решения сложных задач.

6.5 Операторы break и continue
- break - прерывает выполнение цикла
- continue - переходит к следующей итерации цикла
