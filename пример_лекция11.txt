Лекция 11
Обработка исключений

Цель лекции: Изучить обработку ошибок и исключений в C#.

11.1 Блоки try-catch
Используются для перехвата и обработки исключений.
try
{
    // код, который может вызвать исключение
}
catch (ТипИсключения ex)
{
    // обработка исключения
}

11.2 Блок finally
Выполняется всегда, независимо от того, произошло исключение или нет.

11.3 Типы исключений
C# предоставляет различные типы исключений для разных ситуаций.
