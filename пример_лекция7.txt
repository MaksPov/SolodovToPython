Лекция 7
Массивы

Цель лекции: Изучить работу с массивами в языке C#.

7.1 Одномерные массивы
Одномерный массив - это структура данных, содержащая элементы одного типа.
Объявление:
тип[] имя_массива = new тип[размер];

7.2 Двумерные массивы
Двумерный массив представляет собой таблицу элементов.
Объявление:
тип[,] имя_массива = new тип[строки, столбцы];

7.3 Инициализация массивов
Массивы можно инициализировать при объявлении:
int[] arr = {1, 2, 3, 4, 5};

7.4 Обработка массивов
Для обработки массивов используются циклы for и foreach.

7.5 Многомерные массивы
C# поддерживает массивы с любым количеством измерений.
