Лекция 8
Методы и функции

Цель лекции: Изучить создание и использование методов в C#.

8.1 Объявление методов
Метод - это блок кода, который выполняет определенную задачу.
Синтаксис:
[модификатор] тип_возврата имя_метода(параметры)
{
    // тело метода
}

8.2 Параметры методов
Методы могут принимать параметры различных типов.

8.3 Возвращаемые значения
Методы могут возвращать значения с помощью оператора return.

8.4 Перегрузка методов
В C# можно создавать несколько методов с одинаковым именем, но разными параметрами.

8.5 Рекурсия
Методы могут вызывать сами себя (рекурсия).
