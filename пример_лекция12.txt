Лекция 12
Работа с файлами

Цель лекции: Изучить работу с файлами в C#.

12.1 Классы для работы с файлами
- File - статические методы для работы с файлами
- FileInfo - экземплярные методы для работы с файлами
- Directory - работа с директориями

12.2 Чтение из файлов
Использование StreamReader для чтения текстовых файлов.

12.3 Запись в файлы
Использование StreamWriter для записи в текстовые файлы.

12.4 Бинарные файлы
Работа с бинарными файлами с помощью BinaryReader и BinaryWriter.

12.5 Обработка ошибок при работе с файлами
Правильная обработка исключений при работе с файловой системой.
