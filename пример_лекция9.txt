Лекция 9
Классы и объекты

Цель лекции: Изучить основы объектно-ориентированного программирования в C#.

9.1 Классы
Класс - это шаблон для создания объектов.
Объявление:
class ИмяКласса
{
    // поля, свойства, методы
}

9.2 Объекты
Объект - это экземпляр класса.
Создание:
ИмяКласса объект = new ИмяКласса();

9.3 Поля и свойства
Поля хранят данные объекта, свойства обеспечивают доступ к ним.

9.4 Конструкторы
Конструктор - это специальный метод, вызываемый при создании объекта.

9.5 Инкапсуляция
Принцип сокрытия внутренней реализации класса.
